# Таблица ×

Нативный Android-тренажёр таблицы умножения.

## Механика

- режимы на 10, 20 и 30 примеров;
- примеры не повторяются с учётом перестановки множителей;
- используются только ответы от 10 до 99;
- ответ фиксируется сразу после ввода второй цифры;
- удалить или исправить цифру нельзя;
- зелёная обратная связь длится 0,2 секунды, красная — 0,4 секунды;
- ошибочные примеры возвращаются в конец очереди до правильного решения;
- отдельно показываются время первого круга и чистое время всей тренировки;
- для каждого режима хранится отдельный топ-100.

## Сборка

1. Откройте папку `MultiplicationTrainer` в актуальной Android Studio.
2. Дождитесь Gradle Sync. При первом запуске Gradle Wrapper загрузится с официального репозитория и проверится по SHA-256.
3. Выберите `Build > Build APK(s)`.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

На Windows также можно запустить `BUILD_APK.bat`. После успешной сборки APK будет скопирован в корень проекта под именем `Table-Multiplication-debug.apk`.

Минимальная версия Android: 6.0 (API 23).
